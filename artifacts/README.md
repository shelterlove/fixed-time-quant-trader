# 研究产物

`runs/<run_id>/` 保存一次研究运行，完成后不可覆盖。新规则、新数据或实现修改均使用新 run_id。

- `run.json`：策略、实现、数据哈希，Python 与依赖版本。
- `signals.parquet`：全量候选；不得因未来是否能退出而删除信号。
- `hourly/`：首次完整小时悲观回放及分钟需求清单。
- `refined/`：必要分钟细化后的完整连续账户、逐笔成交、逐时权益、准入记录、延期记录、年度与来源汇总。
- `minute_requirements_all.json`：小时与细化路径需求并集。
- `validation.json`（各回放目录）：逐时账本与终点成交现金流核验。
- `REPORT.md`、`baseline.json`：研究结论与机器可读完成状态。
- `status.json`：完成或失败原因；失败不伪装成零收益或无信号。

保存正式基线时，将轻量报告、摘要、核验和运行清单复制到版本管理的 `reports/<run_id>/`。大表与数据在独立存储备份，不进入部署镜像。
