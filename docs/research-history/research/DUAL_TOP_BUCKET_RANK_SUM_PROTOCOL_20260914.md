# 4h与24h双强势组内的排名和策略：预设协议

日期：2026-09-14。先冻结定义，再运行结果。本次继续使用既有本地历史，属于探索性研究。

## 假设

同时位于4h与24h收益前列，可以排除只有单一时间尺度强势的币。在此交集中再要求1h、4h收益排名同步改善，并比较4h与24h排名和，检验“综合最强”或“强势组边缘补涨”哪一种更可能延续。

## 规则

每个完成小时在动态24h成交量TOP100内计算1h、4h和24h收益排名，以及1h、4h排名相较上一完成小时的改善。

分别测试两个强势组：

- TOP5：`r4_rank <= 5 && r24_rank <= 5`；
- TOP10：`r4_rank <= 10 && r24_rank <= 10`。

新开仓候选还必须满足 `r1_improvement > 0 && r4_improvement > 0`。定义 `rank_sum = r4_rank + r24_rank`，测试：

- `max_sum`：买入排名和最大者，代表交集内相对靠后者；
- `min_sum`：买入排名和最小者，代表4h与24h综合最强者。

并列时，最大版本依次选择24h排名更靠后、改善和更大、币种代码更小者；最小版本依次选择24h排名更靠前、改善和更大、币种代码更小者。

## 持有与执行

- 原持仓只要仍同时位于对应的4h和24h TOP5/TOP10就继续持有；
- 排名改善只用于新开仓，不要求持有期间持续为正；
- 跌出任一强势组后重新选择；没有合格币则持有现金；
- 使用下一小时开盘成交；换币30bp，首次或从现金建仓15bp；
- 主版本不设止损，另做30%盘中硬止损敏感性检查；
- 不计资金费。

## 判断标准

比较TOP5/TOP10、最大/最小排名和的毛收益、成本后收益、分期稳定性、换手和现金占比。若成本前收益为负，或2022–2024、2025和2026H1不能保持同向，则停止，不搜索加权排名和或邻近阈值。
