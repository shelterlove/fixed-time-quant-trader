# 24小时收益排名快速上升、新晋Top10研究预定义

日期：2026-09-12，执行前冻结。使用动态24小时成交额Top100，观察UTC 14/15/17；所有历史窗口已被研究，不称为新样本外，不修改生产策略。

- 当前24小时收益排名与4小时前同口径排名比较。
- “可测量新晋Top10”：四小时前排名11—100，当前排名1—10。
- “刚启动”主形态：满足可测量新晋；当前最近4小时收益排名也在Top10；剔除最近4小时后反推的此前20小时收益排名仍在Top10的币。此前20小时收益按 `(1+r24)/(1+r4)-1` 计算并在当前动态Top100内排名。该条件要求24小时强势主要由最近4小时推动，而非此前已经持续强势。
- “快速新晋”作为次级对照：满足可测量新晋，且24小时排名改善值在当时可比较币种中位列前10、改善值为正。
- “外部新晋”：当前Top10、四小时前不在当时成交额Top100或历史不足。因无法知道此前精确收益排名，单独报告，不把此前名次填成101。
- 对照是四小时前和当前都处于24小时收益Top10的“持续Top10”。另报告全部可测量新晋和快速新晋，以拆分“新晋”“快速”“近期启动”的差异。
- 买入参考为观察整点开盘；未来1/4/8/12/24小时整点开盘收益，24小时MFE/MAE和±10%先后沿用上一研究口径。临近窗口末端或路径不完整者剔除。
- 主样本按币种日期保留当天第一次出现；全部观察作敏感性。按2021、2022—2024、2025、2026上半年、2026年7—8月拆分，并计算相对同一时刻持续Top10的24小时收益差及连续7日区块区间。
- 只有刚启动主形态相对持续Top10在2025、2026上半年同向为正、合并区间支持且2021不明显反向，才进入含成本交易回放。否则停止在走势诊断。
