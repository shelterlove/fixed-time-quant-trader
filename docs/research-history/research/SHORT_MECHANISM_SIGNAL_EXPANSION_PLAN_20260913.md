# 空头机制与信号扩展研究计划

日期：2026-09-13。状态：设计完成，尚未执行本计划的新实验。依据当前本地代码及已完成的时点、高点年龄、持有期和形态研究。目标是解释现有信号，并增加成本后有效的独立交易机会。生产配置不变。

## 1. 研究问题与结论边界

现有信号可暂称为“中期强势背景下的短期相对动量骤降＋成交活跃”。它可能混合冲高回撤、上涨中继、持续派发和价格未跌但排名滑落。不能提前认定它识别顶部，也不能把收益较高的06/08解释成已证实的经济规律。

此前全天平均较差、11 UTC部分窗口较好、4–12h高点年龄只在部分时点较好，都说明存在条件交互。广泛探索可以增加，但应围绕机制分组，不做所有阈值的笛卡尔积搜索。此前停止的是特定高点老化形态家族，本次是新的窗口与事件机制研究，不把旧失败规则改名重测。

必须纠正的解释：峰值刷新两次不等于两轮完整上涨；先跌破再反抽的配对只覆盖事后出现反抽的子集，不能代表完整等待策略；当前历史窗口都已被反复查看，时间切分只能衡量迁移，不能称为真正未见样本外。

## 2. 第一阶段：解释原策略与固定时点

### A. 原信号逐层拆解

分别统计：动态Top100 → 强势排名 → 排名恶化 → 成交额变化 → 市场过滤 → 时点 → 每日排序名额 → 账户接纳。报告每层淘汰率、独立事件数、月度频率和新增收益，分辨低密度来自哪道门槛。当前信号选择后约502笔只是已筛选结果，不能代替全体合格事件统计。

做五项一次只移除一层的消融：强势排名、排名恶化、量能、市场过滤、固定时点。主比较固定持有12h，8h和24h为方向检查，全部1–24h曲线作描述，避免用每组事后最优退出解释准入信息。

### B. 排名恶化是否等于实际卖压

收益统一转为对数收益作分解。4h窗口在T与T-4h之间的变化，精确等于最新4h收益减去此前4h收益。分别记录：新进入窗口的价格变化、移出窗口的价格变化、同业变化和动态成员变化。

将原信号分成最新4h绝对下跌、仍上涨但减速、价格基本持平三类；持平只用描述性连续曲线，不凭事后结果挑幅度阈值。比较实际下跌与相对掉队的作用。当前信号并未显式要求r4<0，不能仅凭排名就叫放量下跌。

同时比较同期共同成员排名变化与原动态成员排名变化，检查Top100进出及历史排名缺失带来的影响。历史排名缺失比例按小时报告。

### C. K线形态核对

按年份、06/08及其他时点分层，用固定随机种子抽60个独立事件，盲看信号前72h。先标注急拉回撤、阶梯上涨后失速、高位整理、深跌后反弹失败、无明显绝对转弱，再展示后24h检验定义。额外极端赢家/输家只作失败解释，不参与频率估计。使用真正经回撤确认的波段，避免把每小时新高视为新一波。

### D. 固定时点的四个竞争解释

1. 入场时段：同样状态在不同UTC小时的后续路径不同。
2. 退出时段：收益由经过特定市场时段产生，而非入场钟点。
3. 事件年龄：06/08恰好位于强势启动或动量失速后的相近阶段。
4. 选择偏差：原固定时点筛选历史未知，或候选名额、冷却和数据覆盖造成差别。

用相同入场候选形成入场小时×持有小时热图，同时展示固定退出UTC小时和固定持有长度。比较06/08及邻近05/07/09，11/12作已知探索对照，不再称其为新发现。对时间差做同周、相似r24/r4、波动、成交额和市场状态匹配；匹配只用事前数据，并报告共同支持范围。

记录距首次进入强势组、首次排名失速、最近24/48h高点的年龄。检验事件年龄能否解释时点差异。若获得资金费实际结算时间，才检验相对结算时刻；缺失时不假设所有币都为8小时结算。查不到06/08最初选定依据时明确记为未知。

产出：信号筛选漏斗、机制归因、24×24路径图、盲标事件图册；不在这一阶段选择新交易参数。

## 3. 第二阶段：时间长度与信号扩展实验清单

原基线记为强势24h、短动量4h、排名比较间隔4h、成交额增量1h或4h、流动性选池24h。第一轮约25–30个单因素/明确机制版本，可合并使用同一缓存，禁止全组合。

| 家族 | 固定尝试 | 要回答的问题 |
|---|---|---|
| A 强势时间尺度 | r12、r24基线、r48、r72的Top10 | 领涨身份是否需要超过一天的记忆 |
| B 排除短期窗口重叠 | 以T-4h截止的前24h或48h收益排强势组，T时检测失速 | 排名是否过早剔除了已经开始回撤的强币 |
| C 短期动量长度 | 2h、4h基线、8h；排名比较间隔固定4h | 当前4h是否太慢或太快 |
| D 排名变化间隔 | 1h、2h、4h基线、8h；动量长度固定4h | 更早发现恶化能否提高剩余下跌空间 |
| E 绝对与相对转弱 | 原排名恶化附加r4<0；以波动归一化动量减速替换排名恶化；用相对同业收益减速替换 | 排名滚动效应和真实卖压谁有价值 |
| F 流动性选池 | 仅v24改v48，r24等信号保持不变 | 48h是否主要改善交易池稳定性 |
| G 量能 | 仅1h增量、仅4h增量；自身过去24h中位成交额倍数排名Top5；历史同UTC小时相对成交额排名Top5 | 绝对金额、异常放量、日内季节性谁在发挥作用 |
| H 放宽单道门槛 | 强势Top20；恶化最差20名；量能Top10，分别单改 | 最靠近原条件的新增事件是否有收益 |
| I 连续评分准入 | 三条件候选并集里满足至少两项，归一化评分按训练期校准为原频率约2倍 | 多维联合质量能否替代三个硬阈值交集 |

A与F严格分开；r48收益必须按当时可交易集重新横截面排名，不能沿用r24排序。r48、r72版本需要48/72小时连续数据，所有对照同时给出共同历史覆盖子集，避免币龄差异冒充窗口增量。

B的强势排名在T-4h时的动态交易池中冻结，T时再要求可交易，不能事后用T的Top100重排历史资格。G的自身基准不包含当前被比较窗口；同小时历史只用此前完整数据，覆盖不足保留缺失，不填零。

每个版本独立输出固定06/08和全天事件两套结果：如果只在06/08有效，它改进母策略；如果非06/08新增事件也有效，才可能扩充独立时点。不把所有版本强制叠加高点年龄4–12h，该范围作为已知解释分层。

第一轮最多选择两个有机制依据的交互做第二轮：例如r48＋2h恶化、历史强势排名＋自身异常成交额；须先看到单因素作用，先登记选择理由和固定定义再计算。

## 4. 第三阶段：从固定钟点扩展为事件触发

将强势、失速和失速后的等待分别计时，建立“强势资格 → 首次失速 → 入场/跳过 → 恢复 → 再次失速”的因果状态机。

比较三种方式：原06/08；全天第一次完整满足条件；首次满足后连续两根完整小时仍满足才入场。连续确认是独立版本，不以事后最好小时成交。同一事件多次出现只算一个独立机会；第二次独立事件须先有两根完整小时不再满足失速条件、随后重新触发。无资格恢复时持续掉队不重复开仓。

研究层保存全部触发，执行层未平仓不重复开同币空头；另给原24h冷却敏感性。不得通过未来发现“之后有更好信号”来删除首次亏损事件。等待策略须报告没有再次确认、错过直接下跌的所有母事件。

若第一轮窗口家族有效，再构建快速回撤与慢速失速两支，使用不同事件定义但独立计账。两支高度重叠时只能择优或替换，不能当作新增信号加仓。

## 5. 持有期与成本

先看每个机制完整1–24h均值、中位数、分位数、MFE/MAE、先触及有利/不利5%的比例及剩余收益曲线。最佳点接近24h边界时，统一将该机制家族及其基线补到36/48h，而不是只延长赢家，分别报告共同完整路径子集与缺失事件。

正式参数选择限定4/8/12/18/24/36/48h七个持有期，用训练期曲线选择宽平台中较短的一端；相邻±2h仅验证平台，不再挑精确最大值。所有止损按同口径逐期应用，小时内触发顺序不明者标记，再做分钟复核。

先按固定成本看方向，候选筛选通过后必须补真实资金费、分钟成交和双滑点压力。资金费缺失按未知处理，不填零；0.6%固定成本敏感性不能替代资金费和随持有时长增长的费用。

## 6. 信号密度和组合价值

每个版本报告：每月候选数、每月独立事件数、独立币数、无信号日占比、跨月稳定性、同币同轮上涨重叠、与核心策略的日收益相关、实际接纳数、单位名义额小时收益、最差5%损失。把“旧信号提前/推迟”和“真正新增币/独立事件”分开。

原信号数为1倍，探索频率约1.5倍、2倍的质量变化；只用训练期确定频率/阈值，后续不重新调校。绝不以达到频率倍数作为必须通过的目标。

账户回放顺序：单个新增家族固定单位 → 在原3单位账户中使用剩余容量 → 与放大原信号名义额的等暴露基线比较 → 最多两个家族组合。计入被挤出的多头和空头机会成本、同币重复、退出时点冲突与回撤倍率。信号增长但资金占用更长、账户回撤更差不算成功。

## 7. 验证纪律与进入下一阶段的条件

所有旧窗口已被查看。2022–2024作探索和参数校准，2025、2026H1作固定参数的历史迁移检查，2021与2026年7–8月作压力描述；另外滚动按年份只使用过去选参数并报告全部折。它们都不替代冻结后的新数据。

记录所有实际尝试，以机制家族汇总多重比较；区块重采样保留同周相关、同币事件聚类，计算所选参数收益及相对母策略的配对增量，不仅报告单组均值区间。参数和时点若由同一数据选出，未经选择调整的区间只能作描述。

进入分钟/账户复核：后续两个主要阶段方向为正，增量来源不限于单一年份或少数币，至少形成相邻窗口/持有期平台，新增事件自身有正向收益。2025、2026H1独立事件少于30/20时只记证据不足，不因样本少降低门槛。最终还须完整成本后、等风险暴露下提高账户收益或降低回撤。

停止某个家族的条件：共同覆盖下增量消失；仅重复旧行情；最佳参数随年份大幅跳动；成本吞没优势；只有事后最佳小时赚钱。停止家族不阻断机制独立的其他家族。

## 8. 实施与交付

1. 先完成代码/缓存口径核对：时间可见性、连续历史、原排名能否复现、原成交参考价与研究下一开盘差异、原每小时/每日选择上限。不重复全量测试或哈希。
2. 小时OHLC与横截面数据按窗口读取一次；一次建立2/4/8h动量、12/24/48/72h强势、成交额基准、事件年龄及连续覆盖。派生实验共享缓存和路径，执行脚本存在结果时默认复用，仅对修改过的依赖增量重算。
3. 输出机制报告、实验登记表、候选密度/增量表、24×24路径热图、事件图册、历史迁移结果和最终至多两个候选规格。新规则不直接部署。

优先执行：信号漏斗与窗口分解 → r48及历史强势排名 → 动量长度/比较间隔 → 自身异常量能 → 事件触发 → 少量放宽门槛 → 持有期与账户复核。

方法参考：Bailey等《The Probability of Backtest Overfitting》，https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf 。用于约束大规模尝试后的选择偏差，不用于声称任何交易形态必然盈利。
