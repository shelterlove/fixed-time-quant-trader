# 新上市合约过滤研究结果

运行编号：`20260907_listing_age_filter`，代码版本 1.7.0。

过滤发生在 Top100 与全部横截面排名之前；其他信号条件、三单位容量、成本、资金费、P90、延长和回撤分档保持不变。
第一组严格按用户定义，只排除 `2天 <= 上市年龄 <= 7天`，保留年龄小于2天的合约；这些合约仍需满足原策略约 24–28 小时完整行情门槛。

## 主要结论

三个过滤方案都不建议进入当前策略。长期 research 窗口中，它们同时降低收益质量并显著扩大回撤；2022–2024、2025、2026上半年三个分段均弱于基线。external_2021 的改善与长期窗口方向相反，2026年7–8月仅 7 天方案改善且只有 26 笔成交，证据不稳定。

## 研究限制

上市时间以本地首根 USDⓈ-M 永续合约小时线代理。早于本地数据起点的老合约只会被视为已超过阈值，不影响本研究的 2/7/30 天分类。三个窗口都已用于历史开发，不能称为全新样本外验证。终值受到复利路径影响，应与收益因子、回撤和分段结果一起判断。

结论：保留当前约 24–28 小时自然数据门槛，不新增这三种上市年龄过滤。若以后仍要控制新币风险，应提出不同的、预先登记的风险规则，并留给未见数据验证。
