# 多头策略审计冻结协议

冻结日期：2026-09-14。研究范围以用户提供的七组计划为准。本目录不写生产源码、配置、交易状态、种子或部署；公开行情补充仅写本目录下的 `data/`。

## 基线与因果口径

- 当前工作树而非 Git HEAD 是基线，源码、配置及参数保存在 `frozen_source/`、`source_manifest.json`；既有用户改动不覆盖。
- 原始多头候选为主样本，包括账户未选中候选。候选先冻结，未来行情不能反向改变 TOP100、排名或入场 P90。特征文件与未来标签文件分离。
- 2022–2024 用于三分位边界和固定规则筛选；2025、2026H1分别检查。2021使用2020基础影子预热；2026-07-01至2026-08-28 15:00 UTC辅助检查。所有历史已看过，不是真正未见样本外。
- 近期2026-09-01至2026-09-13 13:00 UTC，只在 `selection_lock.json` 锁定后打开。该期间原生产研究已有授权；本轮用户计划也明确授权。保留当前公开合约目录的潜在存活偏差说明。
- 48h是最长诊断期限；跨期不能读取未来标签，训练末48h事件不用于分组边界和配对统计。历史特征预热可跨界。真实退出依照生产子窗口边界，不以诊断尾部删失改变真实候选。
- 分组少于30个同币同日事件标记样本不足。缺失分钟、缺失资金费、上市预热、内部行情缺口和尾部删失分别统计，缺失不能补零。
- 入场延迟0/1/2分钟分别用T-1至T、T至T+1、T+1至T+2完成分钟的收盘价，计划退出时刻保持基线不变。这是分钟代理，不是逐笔成交复现。
- 原独立账户弃用旧standalone实现，使用当前 `replay_portfolio`，空头候选置空。研究主窗口连续持仓、权益和回撤倍率不重置，再计算子窗口收益及盯市回撤。
- 原始生产执行、候选键、P90、退出原因/时间、价格、资金费和完整组合权益必须复现；离散完全一致，浮点相对和绝对容差各1e-9。不通过则不能比较优劣。

## 七组预先固定研究

1. 末段追涨：24h对数涨幅、最后4h与此前20h单位时间对数涨速差、绝对净对数涨幅/逐小时绝对变化和、距24h最近最高小时收盘时刻的年龄、连续r24 TOP10时长（48h截尾）。三分位边界训练期冻结；三个收益是否全正单列。在相近涨幅、波动、成交额三分位交叉层内复核；不追加入场过滤。
2. 成交额与重叠：v1/(此前23h平均小时成交额)，v4/(此前20h平均每4h成交额)。五个TOP10条件各移除一次，保留原五因子评分和排序。区分原候选、新候选和账户替换；相对放量不直接替换入场条件。
3. 时间：原14/15/17分别持有11/17/18h九组；13–18统一8h邻近时段诊断；独立移除市场过滤。不搜索全天最优时刻。
4. 集中仓位：头名在单候选与多候选批次间按时段、市场状态和评分分层。账户四组：现行、单候选金额减半仍占两单位、单候选金额与占用均为一单位、回撤倍率固定1。生产去重后的单候选判定、碎片单单位和延长让位保持现行语义。
5. 止损与激活：记录首达10/20/30%时间、未激活交易回吐/亏损/止损贡献。硬止损20/25/30%各按原名义金额和0.30/止损距离的金额倍率比较。
6. 利润保护：先关闭延长，比较现行、仅硬止损与时间退出、关闭P17、冻结P90固定30%、取消阶梯直接用冻结P90且保留下限/P17、同币同日影子去重。对改变结果的版本恢复现行延长再查。影子去重采用过去365天内已经完成的同币同日最新基础影子，复用既有研究定义；主样本重复事件检查另用当日首次候选。
7. 延长资格：在原退出仍存活且已激活者中，比较首次激活在最后4h与更早者的随后4/8/24h。账户：现行、完全不延长、所有已激活存活仓位均延长。24h上限和超过4h才让位保持现行。

各组不自动拼接。除影子去重外，所有实验使用原候选的完成基础影子历史，隔离保护历史变化；这是归因口径，不能直接部署。亏损、赢家、未来激活只用于事后诊断。

## 成本、执行和统计

- 固定持有1/4/8/24/48h路径及真实退出收益并存，包含多头双边滑点、手续费及历史资金费（入场不含、退出包含，结算分钟open代理）。仅完整路径提供净标签；缺口不改变候选。
- 手续费和滑点分别按1/1.5/2倍重算执行、成本保护线和账户；资金费率不变。
- 同分钟同时穿越硬止损与已有保护价，比较硬止损优先和已有较高保护价优先。不能使用当分钟新高或刚激活保护来提前退出。这仅是成交约定敏感性。
- 全市场UTC连续日历7日移动区块重采样2000次，种子20260914；包含没有交易的日历日，所有币种一起抽样；30日和同币同日首次事件复核。
- 表格报告事件数、均值、中位数、胜率、最差5%/预期尾部损失、最大单笔、前5笔和前1%盈利贡献。逐年逐币展示。删除头部盈利仅压力诊断，不作为趋势策略必要通过条件。
- 结论逐项归为得到支持/未得到支持/证据不足，注明窗口和反例。统计关联不等同因果。
- 最多两个可执行对照：训练收益和回撤都不劣且至少一项严格改善；2025和2026H1各自不得收益下降或回撤加深。超过两个按训练回撤改善、再终值排序。没有通过则不提出优化。收益风险互有取舍单列，不代替用户选择。
- 最后保持空头信号、退出、成本模型不变，重新回放完整候选竞争，记录空头让位、容量跳过、权益与回撤。不得复用基线成交名单。
