# 多头策略审计

当前工作树的独立研究。范围、固定对照和验收见 [PROTOCOL.md](PROTOCOL.md)，运行完成后结果见 [REPORT.md](REPORT.md)。所有产物和下载都留在本目录；不修改生产代码、配置或部署。

环境使用项目现有 Python、Polars，以及已安装的 NumPy。运行入口为 `run.py`，阶段依次为 `prepare`、`diagnose`、`validate`、`replay --case all`、`report`；详细命令见协议。

代码结构：

- `core.py`：固定窗口/实验、当前生产函数的有限适配、统计与区块重采样。
- `data.py`：逐月因果特征、冻结候选、输入指纹、公开缺口补充。
- `study.py`：基础影子、分钟路径标签、真实退出、连续多头账户。
- `reporting.py`：独立基线复现、归因、门槛锁定和原空头规则下的组合检查。
- `test_audit.py`：研究边界、因果性、执行和仓位的定向测试。

研究入口断点续跑时复用已冻结文件；不要在同一目录中变更生产基线后继续运行。不同基线应使用新的研究目录。程序发生错误会保留带时间戳的失败记录，缺失或无效实验不会被当作通过。

`frozen_source/` 是审计证据，不是第二套可编辑交易引擎。适配层运行时读取当前生产函数、校验修改点后编译，关闭开关时与生产输出完全核对。
