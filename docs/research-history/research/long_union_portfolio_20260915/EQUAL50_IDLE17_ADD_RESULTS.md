# 半仓版：17点无信号时利用剩余资金加仓

本轮以修正后的半仓版为基准：17点完全空仓且有Main信号时只投入2/3。新增规则只在UTC 17点完全没有原始Main信号时触发，把当时全部剩余容量等分加到满足条件的已有仓位。普通信号、同币和当日重入限制、止损封锁及账户回撤倍率保持不变。

五个条件独立回放：

1. `All`：所有已有仓位都加。
2. `AboveEntry`：17点价格严格高于该仓入场参考价。
3. `BelowEntry`：17点价格严格低于该仓入场参考价。
4. `Within5`：17点价格在入场参考价正负5%以内（含边界）。
5. `MFE10`：从入场后到17点已完成小时路径的最大涨幅严格超过10%。

价格条件使用本地小时K线重建的真实入场参考价和17点最新完成小时收盘价，不使用并集适配器中名称相近但实际为布尔标记的旧 `entry_close` 列。

## 结论

没有一个闲置加仓条件在训练期、2025和H1同时提高半仓版权益。把所有持仓都加的规则最不稳定：训练期和2025显著变差，仅在H1大幅受益，同时明显放大回撤。

`MFE10`是收益端最值得继续复核的规则。它把2025从103.85x提高到163.49x，把H1从228.47x提高到300.00x，在2021和7–8月也提高权益；但训练期从834.85x降至669.59x。其加仓中位数在三个主要窗口均为负，收益仍由少数右尾交易驱动，而且回撤升至54.4% / 63.5% / 52.0%，不是稳健的无条件升级。

`AboveEntry`在2021、2025、H1和7–8月都提高权益，方向比“低于入场价”更一致，但训练期降至618.88x，且H1回撤升高。`BelowEntry`只在H1表现好，训练期、2025和2021均变差，不支持简单逢跌加仓。`Within5`最接近原半仓版，但主要窗口没有明显增益。

新增批次使用缓存小时K线：17:01按最新完成小时收盘参考入场，计划次日04:01退出，计入现有手续费与滑点，并做小时级−30%止损近似；资金费未估算。盈利保护或止损附近事件已标记，其中 `MFE10` 在三个主要窗口共有22/89笔需要分钟复核。普通仓继续使用现有hybrid结果。因此本表适合第一轮筛选，不能把复利倍数视为最终分钟精确结果。
