# Next-round research

This directory contains independent, research-only implementations of the
three registered questions: all-hour entry-event quality, loss-recovery
extension, and six new-listing Top15 variants.  It does not modify the frozen
strategy or live execution configuration.

Run `python research/next_round/run.py --help` from the repository root.  The
runner writes caches and outputs to `research/next_round/results/20260907_next_round/`.
