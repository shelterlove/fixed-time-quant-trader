# 三仓策略修复与资金利用率研究计划

制定日期：2026-09-06。状态：计划待执行。本轮仅编写计划和添加忽略规则，不启动实验、不修改交易行为、不部署。

## 1. 目标与边界

先建立可信的净值、订单恢复和三单位基线，再判断空仓来自无信号、容量规则还是执行故障。研究目标是在可接受的回撤与成本下提高组合净收益，不以持仓时间或保证金占用最大化作为目标。

- 所有研究脚本、实验参数、研究测试、临时数据、缓存、日志、图表、报告和结果均放在 `research/`；本项目统一使用 `research/repair_and_utilization/`。
- 已有 `data/`、历史 `results/` 只读复用，不覆盖历史基线；新增下载、派生数据和结果写入本研究目录。
- 实盘状态只通过只读访问或一致性备份分析，备份放本研究目录；不得用研究程序打开可写运行账本。
- 正式缺陷修复落在原 `src/` 模块，必要的产品回归测试落在 `tests/`。实验策略及参数不进入这些目录；研究通过后的产品化另列变更清单。
- 基础策略保持三单位、单多两单位、双多各一单位、空头各一单位、多头让位优先级、P90、硬止损、计划退出、测试网筛选和回撤倍率。任何改变这些规则的实验都使用独立配置并明确标注。
- 签名请求仍只允许 `demo-fapi.binance.com`；保留 Hedge、逐仓和单资产模式。研究阶段不提交交易所订单、不改变现有仓位或账户配置。
- 不新增无必要的哈希校验、重复全量读取或参数穷举。使用运行编号、配置快照、源码差异副本、数据覆盖清单和软件版本记录实验来源。

## 3. 阶段 A：修复与最小复现

先用少量可手算的行情和账户事件复现，再修复；每项记录触发条件、影响、期望结果和验收证据。

### A1. 分钟净值与决策快照的时间一致性

现状：完成分钟价格与查询时的钱包余额、剩余仓位混用。跨分钟成交、部分平仓、手续费和资金费可能污染历史净值。

实施设计：

1. 明确 `minute_end=T` 表示 `[T-1m,T)` 完成后的账户估值，约定边界事件排序。
2. 基于交易所成交和资金流水的实际生效时间恢复钱包与仓位；行情使用对应完成分钟的标记价格。数量、均价、已实现盈亏、手续费、资金费和转账必须归属到正确时间。
3. 决策先处理到期退出并确认订单结果，再取得最近完成且可验证的分钟快照。同批新仓使用同一快照和倍率，持久化后重试沿用。
4. 到期订单若实际成交于 T 之后，不能回填进 T 的分钟净值；其实际可用保证金由下单前检查约束。分钟历史与退出后的执行状态分别记录，不能用一个历史时间标签掩盖两种状态。
5. 峰值来自连续、已验证的分钟净值；已有峰值不能因重启丢失。旧版没有可信分钟历史时，明确首次建立时间，不能宣称恢复了不存在的历史峰值。
6. 外部充值、提现和测试网重置单独登记；未识别的资金变化先阻断新仓，避免把充值识别成策略盈利或静默重置净值。
7. 去掉生产路径回退到实时价格或可用余额的行为；数据不可得时保留待处理状态。

验收：分钟边界前后成交、同刻退出与入场、多空同币、部分成交、手续费、资金费、跨分钟请求延迟均能手算对齐。未来价格或未来事件变化不改变过去的净值与决策。

### A2. 净值缺口恢复

现状：`EQUITY_GAP` 能阻断新仓，但没有验证补齐与解除流程；暂停或重启可能导致持续空仓。

- 持久化缺口起止和回补游标，按缺失区间增量回补价格、成交和资金事件。
- 仅在历史可重建时写入分钟净值；不以前值填充、不用当前钱包伪造过去状态。
- 回补完成后按时间顺序验证连续性、重算受影响峰值及回撤，并原子解除对应阻断。
- 若后续已有标为不完整的快照，仅用于审计，不能直接纳入可交易净值序列。已保存的开仓决策不可事后改写。
- 无法重建时保持清晰、可诊断的阻断；不因经过一定时间自动解除。
- 补数任务有界并与保护、到期退出分离，不能让慢请求停止已有仓位的风险管理。

验收：漏一分钟、多分钟、回补中断、重复回补、重启和真实数据缺失；恢复后只解除已核验的问题，不重复下单或重置峰值。

### A3. 旧仓保护与配置兼容

- `exchange-5s-v1` 与 `exchange-5s-v2` 明确映射到各自应有的交易所增量保护行为；不通过“仅等于最新版本”判断所有旧仓。
- `minute-v1` 保留已约定的兼容路径，未知版本阻断新仓并报告。
- 将新仓要求逐仓 2x 与旧仓风险管理分开。旧 1x 仓位不自动改杠杆；其缺失止损恢复、保护更新及时间退出不能被新仓配置校验提前拦截。
- 保留未知仓位、数量和配置不符阻断；不自动认领或平掉未知仓位。

验收：旧 1x 与新 2x、旧版与新版保护标签、硬止损丢失、保护单更新失败、成交后响应丢失、部分平仓和升级重启。

### A4. 回放计量与完整运行链

- 基础和延长回放均修正线性空头浮盈亏：以入场名义金额为基数时，收益率为 `1 - mark / entry`。例：100 入场、80 标记、名义 100，浮盈 20。
- 区分钱包净值、盯市净值、初始保证金和名义敞口；报告不得将盯市回撤命名成已实现回撤而不作说明。
- 回撤倍率模式必须有完整分钟路径，禁止静默使用仅已实现盈亏的近似值。
- 对齐手续费和资金费实际归属，未结算未来费用或收益不得提前进入峰值。
- 核对多空信号表字段差异及拼接，分钟需求只读取必要列；用短小真实结构样本跑通信号到报告的完整链路。
- 共用计量原语和已验证逻辑，避免基础与延长回放复制同一错误。
- 研究普通成交分钟价格与测试网标记价格分别标记来源，缺少历史标记数据时报告模型限制，不把两者当作同一口径。

### A5. 修复阶段出口

既有 P90、延长、订单恢复、数量步长、最小名义额、生产网拒绝、对账和进程锁回归继续通过。新增测试覆盖 A1—A4 的具体失败场景；143 项旧测试通过本身不能替代这些验收。

三单位总容量、单多两单位、双多各一单位、空头不挤出及让位顺序必须通过；19.999% / 20% / 29.999% / 30% 分别得到 1.0 / 1.1 / 1.1 / 1.3；同批共用倍率，已有仓不因回撤被重设。

产物：`reports/repair_review.md`、最小复现、测试结果及迁移说明。修复未通过时，不对策略变体作收益结论。

## 5. 阶段 C：空仓与资金利用率归因

分别分析历史研究账本和可取得的实际运行账本；本地旧 SQLite 不代表 VPS 当前状态。没有 VPS 数据时，仅报告历史分析并列出缺少的运行字段。

指标按持续时间加权，包含窗口首尾空仓，不按账户事件行数平均：

- 完全空仓比例、0/1/2/3 单位时间分布、平均单位占用率。
- 总名义敞口/净值、净方向敞口/净值、保证金/净值，分别统计。
- 最长及典型连续空仓时间；按 UTC 时段、月份、多空方向和市场状态拆分。
- 净收益、年化复利、分钟盯市最大回撤、回撤持续时间、换手、费用及资金费、收益集中度。
- 净值非正或发生爆仓情形单独报告，不继续用无意义的复利或敞口比率计算。

决策漏斗：数据完整 → 市场过滤 → 个股条件 → 排名/候选预算 → 测试网可交易 → 去重 → 容量 → 对账/净值可用 → 最小订单/保证金 → 截止时间 → 实际成交。

每个候选登记一个明确的最终未执行原因，并保留分阶段数量；不把已接纳计划当成实际成交。并发存在的多个阻断独立记录，时间归因使用预先定义的优先级避免重复累计。

特别区分：全天无信号、非决策时点不交易、退出后等待、剩一单位装不下单多、06:00 候选占用08:00预算、测试网不支持、未知仓位、旧杠杆配置不符、净值缺口、请求超时。

产物：`reports/utilization_diagnosis.md`。该报告决定后续实验优先级；若主要是执行故障，先修复，暂不放宽策略。

## 6. 阶段 D：分批研究新增机会

先单因素后组合，所有实验在运行前登记规则、参数、退出方式、成本、试验编号和指标。以下是首轮预算，不允许看到结果后无限扩展网格。

### D1. 相邻开仓时段：最多 3 个变体

- 基线：当前五个 UTC 时点。
- T1：多头额外增加 13:00 UTC，退出按下一天 08:01 UTC；其他不变。
- T2：多头额外增加 16:00 UTC，退出按下一天 04:01 UTC；其他不变。
- T3：仅在 T1 或 T2 展现稳定增量价值后，研究两者合并；否则不运行。
- 每个新增时点只读取当时完成数据，重新计算排名和因果 P90；遵守相同去重及三单位容量，不对同币已有多仓加仓。
- 比较新增交易、替换掉的旧交易、延长仓让位损失和总组合差异。新增时点也改变持有期限，因此结论表述为整套时段/退出规则的影响。
- 第一轮不改空头时点、日候选预算或保护参数。

### D2. 信号条件贡献：最多 5 个诊断变体

- 分别去掉五个多头排名条件中的一个，其他条件不变，观察被新增接纳的交易及组合影响。
- 该消融仅用于识别各条件的贡献，不直接选择收益最高的版本上线。
- 只有诊断支持时，另行登记最多 2 个轻度放宽候选；不能同时修改市场过滤和多项排名阈值。
- 不把五个条件看成独立概率事件；明确它们之间的相关性。

### D3. 容量碎片：1 个独立变体

仅在单个新多头正常申请两单位、无法合法释放到两单位、但仍有一空闲单位时，允许该新多头开一单位。不加已有仓位，不增加同刻候选上限；其余规则不变。

这改变了当前已冻结的单多两单位语义，只在研究中运行。比较增量收益与后来更优候选失去容量的损失；不能只统计多做了多少笔。

### D4. 一条互补策略：先设计，不与前三项同时调参

- 研究假设：在主策略机会较少的震荡环境中，短周期均值回归可能提供独立收益。尚无已验证收益结论。
- 在 C 阶段后确定一种因果市场状态识别、一个信号和一个退出规则；运行前补齐具体参数，首轮最多 2 个参数版本。
- 先独立验证其净收益，再加入 B3，尤其检查主策略回撤期的表现和共同尾部亏损。
- 组合首版最多占 1 个现有逻辑单位，总容量仍为 3；沿用账户基础单位资金，副策略倍率固定 1.0。该配置作为独立研究方案，不使用2x释放的余额再次计算资金。
- 主策略需要该单位时允许让位，计入真实退出成本和延迟；加入实际组合后逐时点决策，不能用“事后知道主策略未来空仓”的时间段筛选交易。
- 不先铺设多个副策略、全天候网格或复杂动态权重。

## 7. 样本使用、成本与选择纪律

- 已有授权窗口：2022—2026 H1、2021、2026-07至2026-08。它们已被查看或参与历史选择，不能重新称为完全未见样本外。
- 2022—2024 用于机制与开发；2025、2026 H1 分段核验稳定性；2021与2026年7—8月作已见数据上的压力/迁移检验。按时间顺序进行滚动验证，避免随机切分泄露相邻行情。
- `reserved_forward` 的历史策略研究仍保持关闭；若未来要使用2026年9月及之后行情，应另行明确时间边界和用途。修复时读取实际交易日志做故障归因不等于授权该窗口选参。
- 冻结候选后开始向前观察；已揭晓的结果不再用于声称独立验证。
- 完成分钟模型不能精确模拟交易所5秒保护、撤改单延迟或成交先后，报告显式区分研究执行模型与实盘行为。
- 基准成本之外，至少检查手续费/滑点合计为基准1.5倍、2倍；资金费保持对应历史事件。高频变体检查容量和成交滑点，不仅固定比例成本。
- 每个实验均保留结果，包括失败与无效变体。少量预登记实验优先于大规模参数搜索。

候选晋级条件：相对 B3 有成本后的增量价值；跨时间段有一致证据；不是只靠单一年份或少数大赢单；在共同风险预算下仍有优势。报告收益—回撤折衷，不把额外承担风险带来的收益全部解释为策略改善。

若回撤或回撤持续时间明显恶化，即便收益提高也列为风险换收益方案，不自动产品化。样本不足或证据矛盾时，结论为待观察或不采用。

## 8. 性能与可复现性

- 同一数据分区只读一次或按符号/日期分块，复用冻结特征，避免每个候选全量重建市场排名。
- 分钟价格查询建立轻量索引或游标，不在每一分钟对大表重复过滤；避免把多年全市场分钟线全部转成Python字典。
- 每个运行记录实际数据覆盖、缺口、价格类型、配置、费用假设和代码快照；不以内容哈希代替必要的数据与时间边界验证。
- 快照、补数和诊断后台任务不得阻塞已有持仓保护。正式执行维持单写入者、交易意图幂等和持久化游标。
- 产品测试在没有 `research/` 的干净环境仍能运行；研究测试通过独立入口显式执行。

## 9. 执行顺序与最终交付

1. A：复现并修复净值、缺口恢复、旧仓兼容及回放错误；解除产品对研究模块的依赖并完成忽略迁移。
2. B：重建四组可比较基线，解释与历史账本的差异。
3. C：提交空仓归因，确定主要限制来自信号还是执行。
4. D：依次执行相邻时点、条件贡献、容量碎片；互补策略先提交具体定义，再启动有限实验。
5. 汇总 `reports/decision.md`：每个方案采用/拒绝/待观察，列出净收益、回撤、成本、利用率及组合替代损失。
6. 仅将有证据支持且明确选定的规则列入产品化方案；部署沿现有流程单独进行，研究结束不自动上线。

本计划完成的标准是修复验收闭环、可信三仓基线、空仓归因和有限实验的完整结论；不是强制找到一个更高收益版本。
