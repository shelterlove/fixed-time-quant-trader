# 温和回撤倍率与严格 D3 稳定性

所有比较使用相同的三单位、延长、P90、信号与完成分钟估值；仅改变已声明的倍率或碎片语义。

## 回撤倍率

| 成本 | 固定 1.0x：终值 / 回撤 | 温和 1.05x/1.15x：终值 / 回撤 | 当前 1.10x/1.30x：终值 / 回撤 |
|---:|---|---|---|
| 1.0x | 1614845 / -67.07% | 2557759 / -70.48% | 3861387 / -73.65% |
| 1.5x | 547517 / -67.34% | 871396 / -70.76% | 1356027 / -73.94% |
| 2.0x | 183461 / -67.61% | 293125 / -71.04% | 421879 / -74.22% |

温和倍率在三档成本下都处于固定与当前倍率之间：相对固定倍率有更高的样本终值，相对当前倍率收敛约 2.7—3.2 个百分点的盯市最大回撤。它仍是进攻性方案，尚不能宣称会更快恢复峰值。

## 严格 D3

严格规则只接受决策时本来就有 1 个空闲逻辑单位的单多头；不会为了碎片仓关闭空头或已释放延长多头。

- 碎片交易：235，且 `free_units_before` 全部为 1。
- 相对 B3：多 180 笔组合交易；新增 trade_id 229，不再接纳的 trade_id 49。这些是组合重排，不应当被误称为碎片交易本身的独立 alpha。
- 多头优先挤出：25 次；延长多头挤出：5 次；均低于非严格 D3 的 67 和 11 次。

| 成本 | B3：终值 / 回撤 | 严格 D3：终值 / 回撤 | 严格 D3 单位利用率 |

| 1.0x | 3861387 / -73.65% | 9104248 / -69.53% | 30.83% |
| 1.5x | 1356027 / -73.94% | 2851637 / -69.78% | 30.83% |
| 2.0x | 421879 / -74.22% | 819991 / -70.03% | 30.83% |
