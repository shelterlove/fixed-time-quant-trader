# 25%--50% 阶梯倍率与严格 D3：研究决策

新仓统一按开仓前、已完成分钟的盯市回撤决定名义金额：25%→1.05x，30%→1.10x，35%→1.15x，40%→1.20x，45%→1.25x，50%及以上→1.30x。50%是倍率上限；逻辑单位、候选数量、止损与退出规则均不变。

## 全样本与成本敏感度

| 方案 | 成本 | 最终净值 | 盯市最大回撤 |
|---|---:|---:|---:|
| 当前 B3（20%→1.10x；30%+→1.30x） | 1.0x | 3,861,387 | -73.65% |
| B3 阶梯 25%--50% | 1.0x | 2,623,049 | -72.68% |
| 严格 D3 + 当前倍率 | 1.0x | 9,104,248 | -69.53% |
| 严格 D3 + 阶梯 25%--50% | 1.0x | 5,830,843 | -67.82% |
| 当前 B3 | 1.5x | 1,356,027 | -73.94% |
| 严格 D3 + 阶梯 25%--50% | 1.5x | 1,922,045 | -68.06% |
| 当前 B3 | 2.0x | 421,879 | -74.22% |
| 严格 D3 + 阶梯 25%--50% | 2.0x | 615,079 | -68.69% |

严格 D3 加阶梯方案相对当前 B3，在三档成本下都提高期末净值，并将盯市最大回撤收敛约 5.5 个百分点。相对严格 D3 加当前倍率，它在三档成本下都牺牲期末净值，换取约 1.7--2.5 个百分点更浅的最大回撤。

## 跨年稳定性

| 年份 | 严格 D3 + 当前倍率：回报 / 回撤 | 严格 D3 + 阶梯 25%--50%：回报 / 回撤 |
|---:|---|---|
| 2022 | 658.10% / -45.07% | 569.57% / -44.12% |
| 2023 | 1,792.46% / -55.41% | 1,588.12% / -53.17% |
| 2024 | 2,119.20% / -50.26% | 1,961.85% / -47.43% |
| 2025 | 9,253.82% / -64.75% | 8,530.33% / -63.55% |
| 2026 H1 | 2,957.05% / -69.53% | 2,798.97% / -67.82% |

阶梯方案在五个日历切片中均降低回报，也均降低局部最大回撤。因此它的价值是可重复的风险--收益收敛，而不是证明能够更快恢复到历史新高。

## 深回撤路径

与严格 D3 加当前倍率相比，严格 D3 加阶梯方案在 D≥30% / 40% / 50% 的分钟数分别为 639,370 / 291,611 / 101,561，低于 649,136 / 330,642 / 143,375。它减少了深回撤停留时间，但最高峰在样本结束前仍未恢复，不能将此解释为已证实的“更快回本”。

阶梯方案中严格 D3 的 1,749 笔交易有 1,191 笔为 1.0x；其余 558 笔才按阶梯放大，其中仅 40 笔达到 1.30x。它不是持续高杠杆。

## 建议

若实施目标是在保留回撤后增大名义敞口的前提下，控制当前 20%/30% 跳跃式倍率造成的深回撤，采用“严格 D3 + 25%--50% 阶梯倍率”是有数据支持的折中方案。实施前应将倍率表配置化，并为边界、同批次快照、50%封顶、重启恢复和 D3 不挤出仓位增加产品级测试。
