# 主策略与 A/C 的 UTC 组合设计

本次结论：第一验证方案为“主策略优先＋A 的小额补充模块”，C 作为独立对照。尚无证据支持三套信号直接叠加、取交集硬过滤主策略，或者按满足策略数量加仓。本文件为研究设计；未修改生产配置或执行引擎。

## 固定定义和新增诊断

全部时间为全年固定 UTC。Main 保持 r1/r4/r24/v1/v4 各 TOP10 与 market_r24_p10 > −5%；生产入场为14/15/17点。A 为 slope24/v1/v1_vs23 各 TOP5；C 为 r4/slope24/v1 各 TOP5。A/C 沿用原研究流动性池且不增加市场过滤，Main 使用原生产池；两种池的新上市历史要求存在边缘差异。所有市场条件与流动性池差异都是规则差异的一部分，不能把结果全部归因于单个因子。

本轮只读取已有 UTC 事件分区。相同币、相同小时、相同退出节点的收益必须完全一致；七种互斥信号分组分别核对既有重叠表。分时组合先选同币同 UTC 日期的首个合格信号，再检查未来路径完整和跨期边界；不因标签缺失换成更晚事件。

“没有此前主信号”指：截至此刻，当天14/15/17点没有该币的主策略信号，同时点主信号也排除。这是可因果计算的信号诊断，不等于真实账户没有持仓：已有延长仓位、资金不足导致的跳过、空头占用都尚未模拟。未来出现主信号只用于冲突统计，不进入筛选。

以下均为日期等权成本后均值。费用代理每边滑点0.10%、手续费0.05%；不含实际资金费、分钟成交、止损、保护、延长或资金竞争。没有用当日最终信号数倒算可执行仓位。

## 决定组合方式的证据

### A 比 C 更值得先检验补充价值

将各模块自身跨小时同币信号去重，并排除截至当时已发生的主策略信号，统一次日08点退出：

|补充候选|2022—2024|2025|2026H1|事件数（训练/2025/H1）|
|---|---:|---:|---:|---:|
|A：13/14点首次信号|+1.30%|+2.91%|+12.50%|440 / 109 / 54|
|C：14/15/16点首次信号|+0.32%|+1.95%|+3.08%|430 / 102 / 54|
|两者按上述时段并集，首次信号|+0.71%|+1.49%|+8.21%|675 / 168 / 84|

A 的对应超额收益为 +1.43% / +3.88% / +12.86%；C 为 +0.72% / +2.33% / +3.53%。两者均值在三个窗口为正，但尚非新样本验证：这些小时已经看过结果，不能再称冻结后的独立跨期检查。

A 的2025收益95%区间为 [−2.95%, +9.76%]，H1为 [+1.81%, +25.90%]；删除前五盈利贡献事件后，2025为−3.36%，H1为−0.30%。C 的对应区间均跨零，删五后为−2.01% / −2.80%。均值的主要风险仍是少数赢家是否能在组合中实际成交并完整持有。

7—8月上述 A/C 候选分别仅13/14个完整事件，9月截至13日13点分别3/1个；不能用极少数事件的高均值作为选型依据。

### 简单并集会增加信号，但没有提高单位事件均值

以下只是统一08点退出的信号对照，连原策略17点也改为08点；因此不是生产账户收益，也不是生产策略原定退出的均值：

|固定08点退出、同币同日首次入场|训练|2025|2026H1|事件数|
|---|---:|---:|---:|---:|
|仅 Main 的14/15/17点|+1.16%|+5.49%|+11.20%|1273 / 176 / 66|
|Main OR A13/14 OR C14/15/16|+0.68%|+1.68%|+10.29%|1771 / 321 / 134|

并集在三个窗口均值都较低。不过触发日期不同、早入会改变原信号的入场价格、交易数量也增加，因此不能直接把均值下降解释为账户总收益下降。它说明不应把新增候选当成与主策略等质的信号。

### 更多共同条件不稳定地代表更好

统一次日08点退出，A∩C 在15点入场的训练/2025/H1均值为 +0.97% / +11.92% / −3.19%；16点为 +0.24% / +7.60% / −2.42%；17点为 +0.85% / +3.94% / −10.48%。不能把 A/C 共振设成全天通用的加仓条件。

Main14点且满足 A 或 C 的分组为 +3.08% / +36.84% / +20.95%，但2025/H1只有15/13个事件；Main15点同类分组训练不如独有 Main，Main17点同类分组在H1次日08点退出为−3.06%。不存在可以直接照搬到全部主策略小时的“多一票就更可靠”规律。

C16点剔除此前/同时主信号后，次日08点退出均值为 −0.83% / +5.39% / +1.71%，H1只有28个事件。它不能因为低重叠就被认定为成熟的独立补仓时段。

## 第一验证方案：Main＋A，小额共享资金

|模块|信号与入场|原定退出|资金约束|
|---|---|---|---|
|Main|原五项TOP10、原市场过滤，14/15/17点|14/15→次日08；17→次日04；原保护与延长保留|沿用原目标单位数和现有总预算|
|补充 A|13/14点满足 A，模块内同币同日首次；截至此刻没有该币主信号|次日08；首个执行试验只继承原−30%紧急止损，不启用延长|全模块同时最多占1个现有资金单位；不扩大组合总预算|
|C 对照|14/15/16点满足 C，自身首次及相同主信号排除|次日08，与A相同执行约束|作为替代 A 的实验组，不同时另开一份预算|

选择08点用于减少自由参数并与主策略14/15点原退出一致，不声称它已被证明优于06/07点。A 的13/14时段与 C 的14—16时段都是基于已见数据的研究候选，不是新冻结发现。暂不加入更复杂的市场过滤、小时切换、权重或止盈阈值搜索；任何新增市场过滤版本必须重新计算，不能套用表内A/C收益。

执行细则应在下一次账户试验前固定：

1. 每小时先处理现有退出，再处理 Main，最后处理补充模块；实际买入沿用完成小时信号后1分钟的口径。
2. 全局同币只保留一个多头仓位。已持同币则跳过后发信号，不因 A/C 同时触发而翻倍，不重置原入场价、止损或持仓时钟。
3. Main 与补充信号同一时点重合，归 Main。原资金竞争和同币规则先执行；补充仓只用剩余资金，最多1单位、最多同时1个仓位，不为了开补充仓而挤出已有 Main。
4. 后续 Main 在不同币上需要资金时，补充仓可被强制退出以释放资金；这次退出须以实际成交和费用记录，不能继续使用次日08点标签当作收益。Main 的原止损保护不随补充仓变更。
5. 同币后发 Main 仍遵循全局已持仓跳过。这意味着13点 A 可能抢先占用14点 Main 的同币交易机会，必须报告被跳过 Main 的名单与机会成本，不能声称原主策略交易完全不受影响。先不引入接管、加仓、重新定价等更复杂行为。
6. 同时多个补充候选时，按原斜率排名、v1排名、模块第三因子排名、symbol依次排序；这是待验证的确定性执行规则，不是当前日期等权均值已经覆盖的结果。排序与特征缺失使用各模块已经定义的流动性池，不暗中换池。
7. 同币同日最多一次补充入场；当日由于资金不足或已有仓位而未接纳的首个信号也记录为跳过，不因未来标签缺失或后续涨势改善而追选。

A 的“没有此前 Main”信号中，训练有135/441、2025有16/111、H1有10/54随后在当天触发 Main。分母是入场信号数（先于标签清除），不应与上表完整事件数混用。实际冲突是否发生还取决于当时仓位与资金，当前只是潜在冲突计数。

## 只保留三个账户对照

- B0：完整现有组合基线，包括原 Main 的保护、延长和现有空头资金竞争。
- B1：B0＋上述 A 补充模块，组合总预算保持一致。
- B2：B0＋上述 C 对照模块，代替 A，执行和预算约束一致。

先复现基线，再比较相同初始资金、相同成本和实际资金费下的逐段账户增量；不把B1/B2独立事件均值相加，不把未触发日期计为事件收益零，不按已知最终日内候选数分配历史仓位。

每组至少报告实际接纳/跳过笔数、同币后发 Main 冲突、被提前清退的补充仓、原 Main/空头被挤占的收益、分钟盯市最大回撤、资金占用和前五盈利事件贡献。窗口边界与缺失处理保持一致。新增模块至少须在两个跨期窗口计入成本后有正的实际接纳交易收益，整体账户增量不能靠放大预算实现；若机会成本吃掉收益、风险明显恶化或少数交易决定结论，则继续影子观察。账户对照结果仍属于事后检验，最终需要后续未见数据验证。

只有单独补充组证明组合增量以后，才值得研究同时启用 A/C 的共同模块。现阶段不按信号票数加仓、不直接对 Main 施加 A/C 硬门槛、不修改17点原退出。
