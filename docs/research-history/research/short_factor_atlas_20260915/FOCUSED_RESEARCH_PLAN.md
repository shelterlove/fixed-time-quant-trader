# 两组时间路径的双因子与补充单因子研究计划

版本：focus-v1；日期：2026-09-16。状态：已实施；计算结果见 `artifacts_focus_v1/FOCUSED_RESEARCH_RESULTS.md`。

本计划以本次用户要求为准：先完成研究一及原策略对照，再运行研究二；两项均不加止损、不加市场过滤。原空头策略作为对照时同样移除这两项。本文替代此前设计中保留原市场过滤、运行含止损对照的安排。

## 1. 固定范围与共同统计口径

|组别|开空时点|平仓锚点|UTC退出时刻|
|---|---|---|---|
|A：亚洲早段|UTC00、01、02，分别分析|严格晚于入场的纽约10:00|美国夏令时14:00，冬令时15:00|
|B：亚洲午后|UTC06、08，分别分析|严格晚于入场的纽约15:00|美国夏令时19:00，冬令时20:00|

- 只研究以上五条路径。纽约10:00是现有小时研究锚点，纽约15:00是美国后段；二者分别不是09:30现金开盘和16:00现金收盘。
- 沿用本地数据2021-01-01至2026-09-13 13:00 UTC。周末保留，锚点表示当地每日时钟时间，不套现金市场休市日历。
- 每个UTC时点×币是一个事件，因子仅使用该时点前已完成小时数据，参考入场价为最近完成小时收盘价。每个小时独立选币，不做同币同日首次去重，不合成账户净值。
- 所有研究路径固定持有至计划退出，不加止损、止盈、市场条件、资金占用或多头挤出逻辑。
- 空头毛收益为1−退出价/入场价，另列扣0.3%与0.6%固定往返成本的敏感性结果。两组均不计funding；结果是事件收益，不称为可实现净值。
- 主均值按同入场时点候选等权、同UTC日时点等权、日期等权计算；每条固定小时路径就是先日内币等权、再日期等权。另列事件等权均值。没有信号的日期不填0收益，单独报触发日期覆盖率。
- 输出事件数、独立日期数、因子/标签覆盖率、均值、中位数、胜率、P10/P90、最差5%均值、平均MFE/MAE和相对入场冻结TOP100等权做空的超额。分位数、胜率和尾部保留事件口径并明确标注。
- 路径缺失不跨洞插值。个币路径有效、基准不完整时保留绝对收益，超额单独缺失。时期按入场归属，并要求退出不越过该统计时期末端；2026年9月只用截止前成熟的标签。
- 分别展示2021—2025各年、2026已覆盖部分、2026H1、2026年7—8月、9月及全期，不把重叠时期加总为独立样本。

### 如何判断组合有增量

- 每个交集同时对照两个单因子边际，单因子对照限定为双方因子均有效的人群，避免缺失制造增量。
- 报交集相对两个边际的收益差、超额差、MFE/MAE变化、最差5%变化，以及分别相对两个边际的样本保留率。
- 用实际同时满足两条件的币事件计算独立日期；不能把某日分别出现过A和B误记成有A∩B。
- 五分位图用于观察相邻格是否同方向，不从中挑完结果再修改TOP阈值或增加第三个因子。

### 预先固定“最好”的含义

1. 2022—2024作为统一排序窗口，2021、2025和2026各段用于跨期描述。全部时期已被研究过，这不是新的独立样本外实验。
2. 排序窗口至少90个有效事件、60个独立日期才进入主要排名；不以盈利、胜率或超额为正作为入围前提。达不到的仍在完整表中展示并标注样本不足。
3. 对124个固定端部交集，以日期等权扣0.3%均值降序排序，再以相对基准超额、有效日期数、规则编号确定并列顺序。固定成本下毛收益排序相同。
4. 每条路径先确定一个领先组合。再在A组三条路径、B组两条路径中各确定一个“组合＋精确入场小时”的组内领先项，明确其适用小时，不把它外推成整段都有效。
5. 组内领先项还要在同组其他小时展示原样结果，不能按小时/年份临时更换因子或方向。全样本排序仅作为补充，不能替换预定排序窗口的胜出者。
6. 若领先项成本后仍亏损或近期明显反向，直接报告“当前未找到有效组合”；排名第一不自动等于可交易策略。

## 3. 研究一完成后：与原空头选币规则比较

原规则研究版仅保留：

- r24降序名次1—10；
- r4排名变化（T−4h排名减T排名）的降序名次91—100；
- 1小时成交额差降序名次1—5，或4小时非重叠成交额差降序名次1—5；
- 原优先分数和币名并列顺序。

市场P10过滤和30%硬止损全部关闭。名称明确写作“原选币规则研究版（无市场过滤、无止损）”，不用旧的带过滤production_selected标签冒充。

### 对照顺序

1. **相同时间路径对照：** B组各路径领先组合和组内领先组合原样，与原规则研究版在06/08→美国后段比较。这是主要对照。
2. **原规则迁移至早段：** 原规则在00/01/02分别入场、到美国开盘退出，与A组对应领先组合比较。历史排名统一取T−4h，因此00/01/02的历史时点分别落在前一UTC日20/21/22点。
3. **原退出时刻对照：** 固定06→20、08→17，保留同一入场规则与候选，只改退出；同时给原规则及冻结的B组领先规则在两种退出下的配对增量。比较出口时只使用两出口都成熟且完整的共同入场事件。

### 避免混淆选币与组合容量

- 主表比较所有通过条件的候选，统一日期等权，不应用每日3单位或多头优先。原规则“最多选2个”另列原优先分数前2名的诊断；不与新组合全候选结果混为同一层。
- 本轮不做账户回放、06先08后的资金占用模拟，也不添加新的资金管理规则。
- 新组合初筛沿用现有研究TOP100，便于与前期结果衔接。与原规则作直接对照时，双方统一使用生产历史有效性下的TOP100，重算涉及的因子排名，冻结已选组合不重新选冠军；另报池口径变化造成的差异。
- 当前研究TOP100允许部分r24缺失事件，生产当前池要求对应历史完整，不能简单删除研究池中缺r24的币来冒充生产池，因为可能缺少递补币。共同准备阶段用本地行情一次性补齐精确生产池所需信息。
- 原规则的91—100保持固定名次，少于100个有效排名时不改写为BOTTOM10。现有production_candidate仅是每小时已限前2的结果，也不当作完整合格候选复用。

## 4. 研究二：研究一及其对照完成后补充两类单因子

仅研究同样五条时间路径，不新增入场小时，不把新因子立即追加成三因子策略，也不回头替换研究一的冠军。新增定义和窗口在开始计算前写入参数清单。

### 4.1 交易时段历史：8个因子

取严格早于T的上一次纽约10:00和纽约16:00为两个历史锚点A。它们是历史观察起点，不是新增交易路径。各计算四项：

1. **锚点以来收益：** log(C_T/C_A)。
2. **距锚点后高点：** C_T / max(H_(A,T]) − 1。
3. **距锚点后低点：** C_T / min(L_(A,T]) − 1。
4. **成交额相对增幅：** (A,T]成交额总和 / 此前相同小时数窗口的成交额总和。令L=T−A，比较窗口为(A−L,A]；分母为0或窗口缺失则记缺失。

价格C_T为T前刚完成小时的收盘价，(A,T]对应A到T之间完成的小时K线。历史锚点按纽约本地时间处理DST；全程仅使用T前已完成数据。

### 4.2 市场暴露与残差：5个因子

- 个币小时对数收益为r_i,s。市场小时收益m_s固定为当时研究TOP100小时收益的中位数再取log(1+r)，可复用已准备的市场时间序列；不使用当前存活名单回填历史。
- 对每个T和币，固定使用截至T−24h的前720小时样本，拟合r_i,s = alpha_i + beta_i*m_s + epsilon_i,s。这样拟合区间与最长的24小时待评价区间不重叠。
- 至少648个双方有效小时才拟合；小时收益本身不得跨价格缺口，成对缺失不插值。市场方差为0、样本不足或非有限拟合结果均记缺失。
- 输出4/8/12/24小时累计残差：log(C_T/C_(T−h)) − h*alpha_i − beta_i*sum(m_s, s∈(T−h,T])，以及beta_i本身，共5个因子。
- 720小时只用于历史拟合，是本轮明确新增的特殊窗口；不搜索7/14/30/60日最优窗口，不调截尾或正则化参数。

两类共13个新因子。每个因子研究TOP5/TOP10/BOTTOM5/BOTTOM10和完整五分位分布，并给每个入场小时的Spearman IC；IC使用双方有效样本内的平均并列秩。指标与研究一相同。

新因子与相应原收益/位置/成交额因子在共同有效样本上比较，报告排名相关性和候选重叠率，确认是否提供新信息。市场残差不能退化成对所有币减同一个常数。

## 5. 简洁实现与读取安排

建议在现有模块下新增三个研究文件：focused.py负责参数、准备及双因子/原规则统计，focused_factors.py放13个新因子的纯函数，focused_report.py只读取统计产物生成中文报告。复用现有排名、时间转换和路径函数，不建通用插件框架。

输出放在独立`artifacts_focus_v1/`，既有全量产物只读。提供prepare、pairs、compare、new-factors、report及run入口，run按prepare→pairs→compare→new-factors→report执行。

### 一次共同准备

- 先列出阶段所需的全部窄列。月度features、horizon_map和labels各读取一次；筛到五个入场小时、两个美国退出标签、两条原UTC退出标签，真实退出相同的路径继续共享。
- 原始行情仅因精确生产池和13个新增因子所需历史而读取一次。按月顺序加载，保存有限的预热和跨月缓冲；提取并缓存所需OHLCV、币池与市场时间序列，第二项研究启动时不回读原始分区。
- 研究二的额外历史最长为720+24小时收益拟合，需要至少745小时价格预热；缺少本地历史则记缺失，不自动下载。
- 只缓存必要列与五条路径事件，不重算既有127因子。需要重建的生产池排名单独命名，旧排名与新排名不混用。未来标签直接复用；仅补共同比较池中原来未存的币事件，按月一次补齐并记覆盖。
- 完整run在内存允许时共享已加载列；内存不足就分块扫描共同缓存，每块同时计算全部相关规则。独立续跑可读阶段缓存，但不得按因子/因子对重复读行情或整张特征表。

### 紧凑计算

- 31个“因子对×路径”只需预计算排名分组编码，再用布尔交集/分组聚合。避免调用原有127因子全量稀疏矩阵流程，避免事件×全部规则巨大展开。
- 先按实际事件与时点计算交集、边际和日期统计，再跨期汇总；日期数和日期等权均值不可用事件加权矩阵代替。
- 分位数、尾部和完整性只在已经选中的紧凑数组上计算；不为每个规则复制行情。仅为最终对照保留必要事件索引，报告读取统计表。
- 参数使用显式版本与可读JSON，阶段完成记录用于续跑。参数不兼容时要求重建受影响阶段。无原始数据哈希、源码哈希、哈希一致性测试或逐因子bootstrap。
- 记录各阶段耗时、读取次数、事件数量和实际内存使用。先跑一个短期端到端样本据实估算耗时；确认全量程序正常后不反复轮询后台任务。

## 6. 必要验证

只保留影响研究可信度的小型验证，复用已有测试：

1. T后价格变化不改变T因子、动态池或选择；新残差拟合截止符合定义。
2. 手算验证交集、边际共同样本、日期等权、分块合并及零交集日期；五分位25格加总等于双方因子有效的同一标签样本。
3. 美国DST、跨日T−4h历史、严格前一历史锚点与下一退出锚点；成熟标签及时期边界。
4. 原选择函数只放宽市场上下界、保持其余规则，验证去市场过滤研究版的资格、排序、固定91—100名次和前2结果；原始配置单独保留，生产文件不改。
5. 新因子窗口缺口、零分母、零市场方差及拟合不足的缺失处理。用具有已知alpha/beta的构造样本检查残差数值。
6. 准备日志证明单次流程内每个原始分区只读一次；单独重跑report不读取行情、不重算因子。

不增加仅验证文件存在、哈希、格式或照抄实现的单元测试；本轮不做账户回测测试或执行仿真测试。
