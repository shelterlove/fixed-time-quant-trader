# 核心开空路径的单因子类型梳理

研究路径：UTC 00、01、02开空至下一美国开盘锚点；UTC 06、08开空至下一美国后段锚点。美国夏令时的退出分别为UTC14和UTC19，冬令时分别为UTC15和UTC20。

每个因子统一比较横截面TOP10/BOTTOM10。收益为全样本日期等权空头毛收益；成本后扣除固定往返成本0.3%，未计funding。

## 结论摘要

1. `accel24 TOP10`是五条路径中覆盖最广的单因子：五条毛收益均为正，四条覆盖0.3%成本，五条平均毛收益约+0.322%、平均超额约+0.290%。
2. UTC 00—02更适合短期强势反转因子：`r2/r4/r24 TOP10`、`slope4 TOP10`、`close_from_low4/8 TOP10`效果突出。
3. UTC 06、08的其他因子类型均未独立覆盖成本，几乎只有`accel24 TOP10`保留微弱成本后优势。
4. 成交额、波动和K线形态多数具有正超额，但作为单因子不足以覆盖成本，更适合作为后续组合因子。

## 按因子类型推荐继续研究的候选

|因子类型|优先候选|适用路径|判断|
|---|---|---|---|
|加减速|`accel24 TOP10`|五条路径，尤其UTC06/08|跨时点覆盖最广，应作为第一主因子|
|收益强弱|`r24 TOP10`、`r2 TOP10`、`r4 TOP10`|分别偏UTC00、01、02|有效窗口随开空小时向短周期移动|
|趋势路径|`slope4 TOP10`|UTC00—02|与短期收益高度相关，属于强势后反转族|
|高低点位置|`close_from_low4/8 TOP10`|UTC00—02|近期从低点反弹幅度最大的币随后回落|
|成交额量价|`volume_vs_prev24_median TOP10`|UTC01最明显|单独较弱，适合作为组合确认|
|波动标准化|`atr_ratio4 TOP10`、`return_vol24 TOP10`|UTC00—02|大多接近成本线，适合作为组合确认|
|突破/K线形态|`directed_body24 TOP10`、`lower_shadow24 BOTTOM10`|分散|没有单独覆盖成本的领先项，优先级最低|

`relative_rH`与`rH`在同一时点具有相同横截面排序，本报告合并为同一证据，不重复计数。
