## 待核实的仓位版本差异

两笔空头在 BULLA 开仓时尚未退出。约 1000 / 1000 / 2000 USDT 的成交金额不能单独证明违反逻辑容量：逻辑单位与资金金额需要结合版本、净值和冻结倍率判断。

当前 strategy.toml 是三单位并启用严格单空闲单位规则；若两笔空头各占一单位，BULLA 应只获一单位。但 Git 提交 b62fe98 的配置是五单位、1倍杠杆，旧版按 availableBalance / 剩余单位数分配资金。该旧口径可能解释约 1000、1000、2000 的结构。当前提交 c8d3d1d 的提交日期是 09-06，晚于三笔开仓；提交时间本身仍不能证明 VPS 当时运行哪个版本，尤其不能排除当时部署了未提交代码。

需要 VPS 当时的 git commit、strategy.toml、testnet.toml，以及这些 intent/position 的 units、sizing_version、pre_entry_equity、exposure_multiplier 和决策日志，才能给出仓位金额是否错误的最终结论。

本次没有证据将上一轮静态审查发现的让位前保证金检查、回测资金费入账时点或跨窗口延长问题，归因于这三笔实际亏损。
