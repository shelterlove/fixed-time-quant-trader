- 2026-07/08 前向窗口保持不变：31 个候选、28 笔成交、最终权益 1.2640027658070494。

## 已修正问题

1. 组合层此前只按 `priority_score + symbol` 重排多头，丢失白皮书冻结的五因子并列排序。现由信号层产生稳定 `priority_order` 并贯穿执行与组合。相同输入下旧排序精确复现旧权益 73,243.94315577816；正确排序只替换一笔交易：2024-03-29 14:00 UTC 选择 WIFUSDT（因子排名 4/8/4/9/7），不再选择 LTCUSDT（10/4/7/5/6）。
2. 独立多头账本此前没有执行“去重后最多两条、单条两份/两条各一份”的顺序，现与冻结规则一致，并删除未使用的独立账户事件输出计算。
3. 已实现最大回撤此前没有把初始权益 1.0 作为首个峰值；现已纳入。
4. 短线每日容量曾在窗口退出边界过滤前分配，边界外 06:00 候选可能挤占边界内 08:00 候选；现先执行 `planned_exit_time <= window_end`。
5. 小时月分区曾仅凭文件存在即跳过，边界窗口写入的部分月份可能冒充完整月份。现按具体官方对象清单判断，新增日对象与既有月分区合并。此次据此补齐 2021-12。
6. 本地缺失分钟分区曾可能被当成退市终止后缀。现只有官方明确无 K 线标记才允许缺失；内部缺口和未证明的本地缺失直接失败。
7. REST K 线和资金费响应现强制过滤为 `[start, end)`，防止包含式 `endTime` 带入下一日或下月数据；HTTP 长度、可重试状态和具体无效币种错误也已收紧。
8. 资金费空月使用明确官方空事件标记；跨分区重复 `symbol + funding_time` 直接失败。
9. 缓存元数据现在记录真实 warm-up 源起点和最新源 bar，并完整核对参数；前向窗口读取研究影子历史前核对研究 run manifest。
10. 配置启动校验覆盖冻结排名、时段、腿持有/退出一致性、资金费、保护、止损和账户语义；CLI 将研究 bootstrap 与外部 validate 隔离。
