# 仓库整理与代码审查（2026-09-10）

## 本次修改

- 将纯保护定价抽到 `src/fixed_time/protection.py`，回测不再依赖实时策略模块；实时模块保留兼容导入。信号与策略参数不变。
- P17分钟行情读取失败时记录 `P17_RETRY`，仍提交已知基础保护价；下一次轮询重试确认。原实现会在确认读取处抛异常，阻止本轮基础止损更新。
- 旧执行版本的分钟保护路径持久化保护价并取历史最大值，重启后保持单调。原实现跨P9.1阶梯可把107.2的保护价降至101.25。
- 包版本改为读取 `fixed_time.__version__`，修复包元数据1.7.0与运行代码1.8.0不一致。
- 部署记录增加源文件/配置SHA256，区别相同Git提交下的不同未提交代码；只对源码和显式配置计算，不读取凭证。
- 主测试不再导入研究试验模拟器，生产回测的单调性回归保留，并增加旧持仓重启与部署指纹测试。
