# BTC相对强度过滤实验

目的：验证新空头是否应避开短期明显跑赢BTC的币；不直接修改当前主策略。

- 固定 updated_20260918 数据、信号、分钟悲观退出、统一30%止损及所有资金规则。
- 相对BTC强度定义为币种收益率减BTC同周期收益率，单位百分点。使用相同完成小时的1/4/24/48小时收盘收益，不使用未来BTC数据。
- 描述比较历史止损与非止损的中位数、按2021—2024四分位固定边界的分期止损率与净收益；9月独立列出。
- 完整账户只预先指定四个实验：新空头1小时超额达到早期候选90分位不做；4小时同理；二者任一触发不做；以相同数值阈值过滤币种绝对1/4小时涨幅的对照，用于检验BTC是否提供额外信息。阈值仅用2021—2024候选特征，不按盈亏挑选，不搜索最优阈值。
- 其他空头类型和多头不改。过滤作用于当时信号、在持仓准入和批次均分之前；完整回放剩余候选、空出的资金及后续交易，不把删掉旧成交收益当成账户结果。
- 时间段为2021—2024、2025—2026年8月、2026年9月。所有这些历史均已被看过，不称为真正未见样本。
- 逐笔固定样本诊断同时统计少了多少止损、错过多少盈利与平均收益；完整账户报告收益、回撤、成交变化、9月变化和独立账本核验。
