# BTC相对强度：止损识别与完整账户过滤实验

结论：相对BTC涨幅对止损风险有识别价值，但本次直接删除极强候选会同时损失大量历史盈利。4小时过滤显著改善9月，完整历史终值却下降；当前不支持仅凭9月结果直接改主版本。

固定当前数据截止2026-09-18 09:00北京时间，统一30%止损、分钟内悲观盈利保护、原盈利延长与资金规则。所有过滤只作用于新空头，原06空头、多头信号不改。每个账户完整重放资金分配与后续准入。

## 定义与阈值

BTC超额收益 = 候选币同周期收益率 − BTC同周期收益率。例如币4小时+20%、BTC+2%，超额为18个百分点；不是币/BTC价格比变化，也不是先做波动率或beta校正。使用同一已完成小时，不读取未来BTC。

阈值来自2021—2024年 1157 条新空头候选特征的90分位，未按盈亏挑选：1h=8.3380个百分点，4h=15.7936个百分点。候选全部使用，包含当时因仓位/预算未成交的信号。这些只是预先限定的研究阈值，不是最优参数。

## BTC是否提供额外信息

在9月以前新空头样本中，1h/4h的绝对涨幅与超BTC涨幅相关系数分别约0.9954和0.9960：在这类暴涨币样本中，多数相对强度仍来自币自身涨幅。BTC基准有差异，但不是全新的独立信息。
1h或4h的BTC过滤终值高于同数值阈值的绝对涨幅过滤（947.07万对749.31万），两者仍远低于主版本3506.74万。这个比较只支持本组设定下的差异，不能证明BTC过滤普遍更优。9月二者过滤效果相同。

## 验证与下一步

- 五账户全窗口现金流、费用、日初预算、本金占用、归因与清仓验证通过；无过滤基线的成交、小时权益和延长记录与当前主版本逐字段一致。77项规则测试通过，新增测试覆盖BTC时间对齐/禁止跨缺口，以及过滤后重新分配资金。
- 当前主版本和此前逐笔表未被替换；实验保存在独立目录。
- 若继续研究，更值得预先定义相对强度与波动/多小时转弱结构的联合条件，或风险缩放；不能为了保住9月改善反复寻找历史最佳阈值。本轮没有测试或证明这些后续方案。
- 结果为有限候选条件的历史研究，不是未来收益预测。分钟执行近似、资金费、容量和强平模型缺失等原边界仍存在。
