# 当前规则补充：统一 30% 止损，300/270/400 盈利保护

版本 SPEC-20260917-r2。用户本轮明确指定，适用于离线主版本；r1 结果保留为历史对照。

1. 所有多头来源、新空头、原版 06 空头的硬止损统一为入场参考价不利变化 30%。其余信号、资金分批及持仓限制沿用 r1。
2. 每个多头 lot 独立计算：价格达到入场参考价 ×4（盈利 +300%）后，永久激活固定保护线 ×3.7（盈利 +270%）；此后触及保护线全平该 lot。保护线不随新高上移，不是从峰值回撤 30%。
3. 价格达到入场参考价 ×5（盈利 +400%），全平该 lot。不同成本的追加 lot 独立触发；不依据其中一个 lot 的盈亏清空其他成本 lot。
4. 空头仍执行 30% 硬止损及既有到期退出。这是价格涨幅口径的多头保护规则；以入场名义本金计的无杠杆空头盈利不能达到 +300%。
5. 既有多头 +30% 盈利延长资格、计划退出和最多延长 24 小时保持不变。300% 激活不取消到期退出，不创造额外延期。盈利退出不计作亏损硬止损日锁，同日已买入限制继续生效。
6. 开盘是已知最先时刻。此前已激活保护且开盘低于保护线，按开盘较差价格退出；开盘已经超过 400% 时按 400% 阈值退出，不给予有利跳空奖励。所有退出仍加双边既有费用与不利滑点。
7. 小时内采用连续价格路径：O→L→H→C、O→H→L→C；若未激活且本小时可先越过 300% 再回落保护线，还计算 O→300%→L→H→C。达到事件即退出，之后的高低价不计入持仓权益。
8. 主版本选择上述可行路径中该 lot 小时末价值较低者（已退出用结算金额，未退出用收盘浮盈）；另完整回放两种固定高低顺序作为敏感性对照。该局部保守选择不是账户复利收益的严格下界，也不是精确分钟成交。止损与止盈冲突按各路径的真实先后执行，主版本避免选择有利事件覆盖可行的亏损事件。
9. 风险包络使用所选路径退出前的极值及退出费用，不纳入退出后的高低价；跨币极值仍非同步，也不是实际盘中净值。
10. 四个新账户：保守主版本、先低后高、先高后低、关闭延长的保守对照。另重跑统一 30% 无盈利保护双版本，与前轮逐笔及逐小时结果核对。输入行情不更新，信号从冻结行情全量重建后核对，重新核验资金、费用、日界线、清仓和归因。

11. 本轮复核发现已有本地分钟数据，因此追加三组分钟细化账户：仅当该小时 60 根分钟线完整、合法且聚合 OHLC 与冻结小时线一致才使用，逐分钟推进同一状态机；分钟内仍不明的先后按第 7—8 条处理，分钟缺失回退小时路径。信号、分批和账本结算时点仍为小时。当前较充分的数据结果见 [分钟细化结果](PROFIT_GUARD_MINUTE_RESULTS.md)，纯小时结果保留。分钟细化独立运行 `python -m v2.minute_guard_study`，禁止覆盖已完成结果。
