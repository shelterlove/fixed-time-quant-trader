# 全部空头入场前后24小时：走势对照

范围：2026-09-18 冻结快照的全部1520笔实际空头，68笔硬止损、948笔盈利、504笔未止损亏损。没有按未来行情完整性删交易：全部48小时窗口数据齐全，共72,960根K线。原交易规则、成交、费用与仓位保持不变。

每笔包含入场前24根完整小时线（结束于T−23…T）和入场后24根（结束于T+1…T+24）；额外取T−24收盘作为涨幅锚点。T为决策小时，原回放近似成交时刻为T+1分钟；未剔除入场后第一小时最初一分钟。价格统一除以入场参考价。窗口延续至T+24，即使原交易已经退出；未来走势并非原策略继续持仓的收益。

## 1. 入场前：方向形状类似，幅度与波动不同

下表是逐笔指标中位数；不同区间中位数不能直接连乘当成一笔真实路径。

|指标|止损68笔|盈利948笔|普通亏损504笔|
|---|---:|---:|---:|
|前24h至前12h涨幅|+7.96%|+3.22%|+3.10%|
|前12h至前4h涨幅|+5.73%|+3.47%|+2.15%|
|最后4h涨幅|+13.45%|+6.20%|+5.43%|
|完整入场前24h涨幅|+31.73%|+15.21%|+12.46%|
|入场ATR4/价格|9.02%|4.69%|4.41%|
|前24h上涨小时数|14|14|14|
|前24h最大收盘回撤|8.27%|6.09%|6.25%|
|距前24h最高价回落|6.22%|3.49%|3.58%|
|最后4h平均成交额/此前20h均值|2.08倍|1.67倍|1.56倍|

三组都普遍先涨、最后几小时再加速，并不是止损组此前完全不回调而盈利组已经明确下跌。止损组涨幅与波动大；按入场ATR缩放后，中位路径更接近，但未完全重合。24h涨幅/ATR比例中位数分别4.56、3.41、3.01；4h涨幅/ATR分别1.73、1.43、1.33。不能把“图形较像”表述成已证明没有入场预测信息。

## 2. 入场后：继续上涨放量，与缩量回落分开

|距入场时间|止损组价格变化中位数|盈利组|普通亏损组|
|---|---:|---:|---:|
|1h|+1.28%|-0.77%|+0.39%|
|2h|+5.12%|-1.45%|+0.82%|
|4h|+10.82%|-2.46%|+1.24%|
|8h|+20.76%|-4.00%|+2.38%|
|12h|+24.03%|-5.58%|+3.36%|
|24h|+17.12%|-7.09%|+3.40%|

- 入场后4h成交额/入场前4h成交额，中位数分别1.67、0.92、1.03倍。止损组的活跃程度往往在进场后继续增加。
- 后24h盘中最高价相对入场的涨幅中位数，分别48.77%、3.52%、12.17%。止损组定义本身包含曾触及30%，因此这属于事后路径描述，不能据此宣称提前预测成功。
- 后24h最高价出现时间中位数，止损组为第9小时，盈利组第2小时；最低价出现时间分别为第2、第17小时。每笔高低时间可能不同，不应把边际中位数拼成唯一的“典型交易”。
- 盈利组也有332/948笔第一小时收涨，387/948笔前4小时突破了入场前4小时高点。看到一根上涨或一次创新高，并不能直接判定这笔一定止损。

## 3. 止损组不是单一失败路径

68笔中23笔在入场后3小时内止损。排除止损所在小时的高低先后歧义，28笔止损前曾出现至少5%的有利下跌，只有5笔至少10%。

考察先到+10%还是−10%：62笔先到+10%，3笔先到−10%，3笔在同一小时触及两侧、无法判定顺序。说明对绝大多数止损单，“等待足够大的有利下跌再兑现”并没有先给出机会。小幅有利下跌后再次上涨仍常见。

## 4. 止损后是否回来：没有统一答案

观察终点统一为入场后24h，不是止损后再延长24h。

- 20/68笔（29.4%）到T+24收盘低于入场价；48笔仍高于入场价，其中24笔仍在+30%以上。
- 28笔在止损小时之后的完整小时中曾触及入场价或更低，另28笔曾继续到相对入场+50%以上；两组可重叠。
- 40笔止损所在小时收盘低于+30%，但这并不意味着之后不会继续上涨。单看触发小时上影线会漏掉后续延续行情。
- 原未止损交易中47笔在完整后24h内也曾达到+30%，其中9笔原先盈利、38笔普通亏损。这些触及发生在原退出之后，不应该重新标成原策略的止损交易。

九月例子（相对入场价格，不是交易净收益）：

|币|后24h最高涨幅|第24h收盘涨跌|
|---|---:|---:|
|LSK|+159.40%|+131.56%|
|MTL|+32.80%|-4.92%|
|AIN|+48.60%|-74.67%|
|SYN|+126.04%|+74.38%|
|ONE|+145.36%|+73.10%|

MTL、AIN体现先止损后下跌，LSK、SYN、ONE体现大幅继续上涨。后者说明不能根据前者推导放宽或取消止损有利。

## 5. 排除已经止损的交易后，早期走势仍有信息

为了避免“已经止损所以看起来涨很多”的循环解释，仅在指定小时结束时仍持仓的交易中，看后续是否止损。

入场2小时后有1506笔仍持仓；已经触发的14笔止损不参与下面比较：

|当时价格状态|仍持仓交易|后续止损|后续止损率|原交易最终平均净收益|
|---|---:|---:|---:|---:|
|价格比入场高至少5%|132|23|17.42%|-7.74%|
|未达到上述条件|1374|31|2.26%|+2.75%|

高风险132笔中仍有35笔最终盈利。这里的-7.74%是原规则最终收益，不是此刻提前退出的收益，也不是能够节省的损失。加入放量≥1.5倍后，第2小时组的后续止损率未进一步提高；“继续放量”的组间特征不应自动转化成叠加过滤有效。

这支持研究“入场后走势未按预期转弱”的持仓管理或延迟确认，但尚未进行对应策略回放，不能作为入场过滤使用。全部历史均已被研究，阈值描述不是独立样本外验证。
