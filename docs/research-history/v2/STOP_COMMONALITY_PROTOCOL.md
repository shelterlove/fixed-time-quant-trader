# 止损共同点诊断口径

目的：解释当前统一30%止损策略的历史止损共同点，重点研究9月新空头集中止损，不直接修改交易规则。

- 样本为 updated_20260918 完整回放中的实际成交。按多头、新空头、原06空头分开，不把同一种涨势对多空的相反含义混在一起。
- 主要比较截至2026年8月的新空头止损与未止损；2026年9月单列。未止损不等于盈利，同时报告净收益和胜率。
- 所有特征只用入场前已完成小时。市场均值定义为当时R池成交额前100币的等权算术平均，不把已有P50中位数叫作平均数。相对强度用币收益减市场均值，单位为百分点。
- 特征族固定为：R1/R4/R24/R48及相对市场超额；4小时对数动量加速度、前4小时涨幅；ATR4/价格；成交额放大倍数；市场48小时状态；最近4小时高点回撤、末根K线方向及收盘位置。
- 描述统计看中位数，风险分组用2021—2024新空头特征四分位边界冻结后，分别检查2021—2024、2025—2026年8月、2026年9月。时间分段不假称未见样本。
- 辅助检验只看预先固定的粗条件：R4超额≥15个百分点、R48超额≥30个百分点、ATR4/价格≥8%、成交额倍数≥5、市场R48 P50>-2%、最后1小时下跌、最近4小时高点回撤≥5%。不搜索最佳阈值或所有组合。
- 按年、币种/入场日和等入场日口径核对，避免同日重复成交被当成完全独立证据。止损率高不自动等于适合过滤，须同时检查被排除的盈利交易和净收益。
- 不在本轮重跑参数优化或修改策略；输出可复核数据和解释。

首次结果后追加的探索项：发现9月5笔新空头止损入场时均为“市场R48中位数<0但算术均值>0”。单独检查这一均值/中位数分歧在历史及两个时间段的关联，明确标为事后提出的探索，不冒充预先登记条件，也不搜索其最佳阈值。
