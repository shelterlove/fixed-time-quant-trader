# 本轮实验口径

- 固定既有数据、信号、时间窗口、分批资金、仓位限制、费用和回撤计算。
- 对全部多头类型和两个空头类型分别统一采用 20% 或 30% 价格止损。各跑盈利延长开启/关闭，合计四个账户，与既有混合止损基线对照。
- 止损仍优先于盈利延长及计划退出，跳空按较差开盘价处理；风险包络与真实退出使用同一止损配置。盈利延长触发仍为 +30%，不跟随止损幅度变化。
- 多头阈值固定为 80%、100%、200%、300%。沿用原基线主版本和仅止损版本的实际持仓样本，计算首次触达后的最终收益、假设阈值退出收益及净差，并提供逐年和收盘确认统计。不直接修改止盈规则。
- 复用共享引擎，不复用旧交易结果生成新账户；不重建冻结信号、不覆盖基线。
- 验收：规则测试；四账户完整窗口回放及独立现金流验证；100%/200% 重复诊断与前次完全一致；保留可复核逐笔明细和参数。

运行：`python -m v2.stop_threshold_study`。已存在的实验目录禁止覆盖。
